It contains Jupyter Notebooks focusing on data analysis. This notebooks are the final projects of the modules of a data science course taught by INFOTEC in colaboration with Meta.

Proyecto Introducción al Análisis Estadístico: A project about statistical analysis, it explores a data set through descriptive analysis, visual identification of patterns and linear regression.

Proyecto Introducción al Análisis Exploratorio de Datos: It explores a public data set. First, data cleaning is done. Then a statistical analysis is made: data visualization, filtering of outliers and correlations between variables is explored. Finally, a visual narrative is constructed with the information gathered.

Proyecto Introducción al Aprendizaje Automático: The knowledge in the other two projects is used in a data set of electric vehicles. Also, basic Machine Learning techniques are used to further explore the data set.
